## 소개

머신러닝과 컴퓨터 비전 모델을 실제 동작하는 소프트웨어 시스템으로 구현하는 **AI & Software Developer**입니다. AI 모델링과 애플리케이션 개발을 분리된 영역으로 보지 않고, 데이터 전처리·모델 학습부터 REST API 설계, 데스크톱/웹 클라이언트, 실시간 로보틱스 제어까지 전체 파이프라인을 아우르며 문제를 해결합니다.

- **핵심 관심 분야:** 응용 머신러닝(Applied ML), 컴퓨터 비전(YOLO), 백엔드 API 설계, 클라이언트-서버 애플리케이션
- **시스템 통합 경험:** Python ML 파이프라인과 C#/.NET·React 클라이언트 연동, 비즈니스 백엔드 내 LLM 워크플로우 통합, WebRTC 기반 실시간 엣지 비전 스트리밍
- **개발 방식:** 동작하는 프로토타입과 체계적인 실험으로 아이디어를 검증하고, 점진적인 리팩토링을 통해 시스템 완성도를 높입니다.

## 주요 프로젝트

### 1. ChurnGuard — 고객 이탈 예측 및 모델 평가 시스템 `[Prototype]`

**저장소:** [bitTask-ChurnGuard (ML API 서버)](https://github.com/Cov4w/bitTask-ChurnGuard) · [bitTask-Churnguard-Client (WPF 클라이언트)](https://github.com/Cov4w/bitTask-Churnguard-Client)

- **목적:** 고객 이탈 예측을 위한 데이터 전처리·모델 학습·성능 비교를 클라이언트-서버 구조로 통합하여, 고객 유지 전략 수립으로 확장 가능한 ML 평가 워크플로우를 구축했습니다.
- **핵심 구현 기능:**
  - `ColumnTransformer` 기반 자동 전처리 파이프라인(중앙값/최빈값 결측치 처리, `StandardScaler`, `OneHotEncoder`, 계층적 분할)
  - 5개 분류 모델(Logistic Regression, SGD Classifier, Decision Tree, Random Forest, Gradient Boosting) 동시 학습 및 지표 비교
  - C# WPF(MVVM) 데스크톱 클라이언트에서 FastAPI 엔드포인트(`POST /api/model-improvement`, `GET /api/model-report`)를 호출해 하이퍼파라미터를 실시간 실험하고 5-Fold `GridSearchCV` 최종 선정 리포트 조회
- **주요 기술 스택:** `Python` `FastAPI` `Scikit-learn` `Pandas` `C#` `.NET 9` `WPF (MVVM)`
- **기술적 포인트:** 불균형 데이터 특성을 고려해 F1-Score와 ROC-AUC(`predict_proba` 및 `decision_function` 분기 처리) 기준으로 최적 모델을 선정하도록 설계했으며, 타입 기반 REST API로 Python ML 학습 로직과 데스크톱 UI 상태를 깔끔하게 분리했습니다.

### 2. THE BOOK ARCHIVE — AI 기반 도서 쇼핑 데스크톱 애플리케이션 `[Team Project]`

**저장소:** [bit-midtermProject](https://github.com/Cov4w/bit-midtermProject)

- **목적:** 명확한 클라이언트-서버 아키텍처 위에서 도서 검색·구매 및 관리자 기능을 제공하고, LLM을 결합해 도서 요약과 맞춤형 독서 성향 분석을 지원하는 데스크톱 애플리케이션을 구현했습니다.
- **핵심 구현 기능:**
  - **사용자 기능:** 회원가입·로그인, 키워드·카테고리·가격 조건별 도서 검색, 장바구니 및 결제, 구매 이력 조회
  - **관리자 기능:** 회원 및 결제 상세 내역 조회, 도서 판매 상태 관리, Kakao Book Search API 연동을 통한 도서 데이터 동기화
  - **AI 기능:** OpenAI 호환 Chat API를 연동한 도서 핵심 요약, 구매 이력 기반 독서 성향 진단 리포트, 대화형 도서 추천 상담
- **주요 기술 스택:** `C#` `.NET 8` `WPF` `ASP.NET Core Web API` `MySQL` `Entity Framework Core (Pomelo)` `Swagger` `OpenAI SDK`
- **기술적 포인트:** `BookShopping.Client`와 `BookShopping.Server` 간 REST 통신 구조를 설계하고, EF Core 조인으로 추출한 실제 구매 이력을 LLM 프롬프트 컨텍스트로 결합했으며, `ApiService`에 명시적 HTTP 상태 코드 예외 처리를 적용했습니다.

### 3. Unitree Go2 순찰 및 WebRTC 원격 제어 시스템 `[Team Prototype · v0.1.0]`

**저장소:** [nCAGE (패키지화 버전)](https://github.com/Cov4w/nCAGE) · [cage-unitree-project (팀 작업 저장소)](https://github.com/Cov4w/cage-unitree-project)

- **목적:** 사족보행 로봇 **Unitree Go2**를 활용한 자율 순찰 팀 프로젝트(ROS2 SLAM/Navigation 연구 병행)에서, 웹 기반 실시간 모니터링·원격 제어 및 비전 이상 탐지 파이프라인을 담당해 구현했습니다.
- **핵심 구현 기능:**
  - `go2_webrtc_connect` 및 **WebRTC(`aiortc`)** 기반 저지연 카메라 스트리밍과 웹 조이스틱·동작 모드 원격 제어
  - `multiprocessing.Queue`를 활용해 비동기 WebRTC 프레임 수신과 **Flask + Flask-SocketIO** MJPEG 영상 송출을 연결
  - **Ultralytics YOLO(`yolo11n` / 커스텀 `best.pt`)** 기반 실시간 사람 탐지 및 지속 시간·신뢰도 임계값을 적용한 화재 감지·반복 알림 제어, `nCAGE` 내 LiDAR 뷰 모드 전환 기능 통합
- **주요 기술 스택:** `Python` `Flask` `Flask-SocketIO` `WebRTC (aiortc)` `OpenCV` `Ultralytics YOLO` `Unitree Go2`
- **기술적 포인트:** `asyncio` 기반 WebRTC 스트림과 동기 Flask/Socket.IO 루프 간의 병목을 큐 구조로 분리해 안정화했으며, 연속 감지 시간 기반 필터링으로 화재 오탐 알림을 줄이고 초기 프로토타입을 `pyproject.toml` 기반 설치형 패키지로 리팩토링했습니다.

### 4. 자가 진화형 암호화폐 자동매매 시스템 `[Personal System]`

**저장소:** [upbit-auto-trading-bot](https://github.com/Cov4w/upbit-auto-trading-bot)

- **목적:** 머신러닝 기반 매매 시그널 생성, 실시간 포지션 모니터링, 자동 리스크 관리 및 백테스팅을 하나의 풀스택 플랫폼으로 통합했습니다.
- **핵심 구현 기능:**
  - 거래량·추세·시장 상관관계 필터와 3-Class **XGBoost / Scikit-learn** 모델을 결합한 다단계 진입 전략 및 최근 매매 기록 기반 시간 가중 재학습
  - 최대 낙폭(MDD) 감시, 트레일링 스탑, 급락 긴급 청산 로직 및 멀티 코인 백테스팅 모듈
  - JWT 인증 기반 **FastAPI + WebSocket** 백엔드, **React + TypeScript** 실시간 대시보드, **Docker Compose + Nginx** 컨테이너 배포 환경
- **주요 기술 스택:** `Python` `FastAPI` `XGBoost` `Scikit-learn` `WebSockets` `React` `TypeScript` `SQLite` `Docker` `Nginx`
- **기술적 포인트:** 매매 실행·자본 관리·백테스팅 모듈을 역할별로 분리하고, WebSocket으로 실시간 포지션과 모델 성능 지표를 스트리밍할 수 있도록 Docker 기반 서비스 구조로 정리했습니다.

### 5. 머신러닝 · 딥러닝 학습 및 구현 아카이브 `[Study & Implementation Archive]`

**저장소:** [bit-MachineLearning-study](https://github.com/Cov4w/bit-MachineLearning-study)

- **목적:** 고전 머신러닝부터 심층 신경망까지 핵심 이론 정리와 재현 가능한 구현 코드를 함께 축적하는 기술 아카이브입니다.
- **주요 구현 주제:**
  - **지도 / 비지도 학습:** 로지스틱 회귀, 결정 트리, Stratified K-Fold 교차 검증, 그리드 서치, K-Means 군집화, PCA
  - **딥러닝 아키텍처:** ANN, DNN, CNN(필터 및 특성 맵 시각화 포함), 순차 모델(RNN, LSTM, GRU)
  - **듀얼 프레임워크 구현:** 핵심 신경망 모델을 **TensorFlow/Keras**와 **PyTorch** 두 프레임워크로 모두 구현하며 학습 루프와 추상화 차이를 비교 정리
- **주요 기술 스택:** `Python` `PyTorch` `TensorFlow` `Keras` `Scikit-learn` `NumPy` `Matplotlib`
- **기술적 포인트:** 블랙박스 API 호출에 그치지 않고, Keras와 PyTorch 구현을 병행하며 순전파·역전파 흐름, 과적합 제어, 특성 추출 원리를 코드 수준에서 검증했습니다.
